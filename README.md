=>personal firefox extension that lets me block certain websited from being accessed.
=>this extension hasnt been published so it can be set up locally if you'd like.
=>in this repo i've blocked access to the following websites:
-reddit.com
-instagram.com
=>to set up locally:
-search for "about:debugging" in firefox
-this firefox
-load temporary add-on
-choose the manifest.json file and thats it
=>to add another website just add the website's domain under requestDomains inside rules.json
